# Badcase 分析模板

> 编号：bc-______  日期：______  发现人：______  
> 所属项目：SFT / RLHF / 评测 / 采集

## 1. 现象

一句话：标注/评测/数据里出现了什么不该出现的结果。

## 2. 样例

贴原文（指令 + 回复 + 当时的标注/评分）。截断可以，别改写。

## 3. 根因

勾选并展开：

- [ ] 规范没写清（SOP 缺这条）
- [ ] 规范写了没人看（培训/可读性问题）
- [ ] 两个规范打架
- [ ] 标注员理解偏了
- [ ] 模型输出本身难判（灰区）
- [ ] 工具/格式问题

## 4. 影响

多少条受影响？是单条还是模式性？会不会进训练集？
