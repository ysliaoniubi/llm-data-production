# 出题与评分细则设计

目标：题目**可作答、可评分、可区分**。出题不是炫技，是给模型和标注员一个干净的考场。

## 1. 好题的四个条件

1. **指令无歧义**：一个懂该学科的人读完知道要交付什么
2. **有客观抓手**：字数、要点、步骤、结论可核对
3. **难度有梯度**：基础分能拿到，高分要真本事
4. **不依赖未给信息**：材料给全，或明确"可使用常识"

## 2. 题型模板

### A. 常识 / 逻辑推理
- 题干：生活或工作场景 + 明确问题
- 考点：前提识别、隐含假设、因果
- 评分：结论对错 + 关键步骤是否给出

### B. 文本写作
- 题干：身份 + 对象 + 目的 + 格式 + 硬约束（字数/禁词/必含要素）
- 考点：指令遵循 + 结构 + 语言
- 评分：rubric 分项，硬约束一票否决

### C. 材料分析
- 给一段有漏洞的论证/数据/合同条款
- 要求指出问题并改写
- 评分：找没找到 + 改得对不对

### D. 多轮任务
- 第一轮布置，第二轮改约束，考察上下文保持
- 评分：第一轮质量 + 第二轮是否丢掉第一轮要求

## 3. 参考答案写法

参考答案不是"一篇范文"就完了，要包含：

1. **关键得分点清单**（阅卷人照着勾）
2. **常见错误**（预测模型会怎么错）
3. **可接受变体**（结构不同但达成目标也算对）
4. **满分示例** + **6 分示例**（如果用 10 分制）

## 4. 评分细则（rubric）写法

硬约束（不合格直接判 ≤4 分）：
- 跑题 / 字数差 > 20% / 缺必备要素 / 事实硬伤 / 安全违规

软维度（分项打分）：
| 维度 | 0 分表现 | 满分表现 |
|---|---|---|
| 切题 | 答非所问 | 全程围绕任务 |
| 完整 | 缺关键步骤 | 步骤闭环 |
| 准确 | 结论错 | 结论对且依据足 |
| 表达 | 语病多、套话 | 清晰、匹配文体 |

**规则**：rubric 写完自己假装是阅卷新手，能否 5 分钟内知道怎么打分；不能就是 rubric 不合格。

## 5. 学科覆盖（示例）

| 领域 | 出题注意 |
|---|---|
| 常识 | 用真实生活场景，不考偏门冷知识 |
| 写作 | 禁词和必含要素要少而狠，3 个以内 |
| 逻辑 | 不出有争议的脑筋急转弯 |
| 金融/法律/医疗 | 只出通识级，专业意见要加"仅供参考"限定 |
| 代码 | 给语言版本和输入输出样例 |

## 6. 质量自检

出完一题问自己：
1. 我能不能 3 分钟内按自己的 rubric 给一篇中等回答打出唯一分数？
2. 两个合格阅卷人打分会不会差 ≥3 分？会 → rubric 太粗
3. 这题百度一下是不是 10 秒就有原题？是 → 换场景
